# 🚚 QuickShip - Shipment Service

A static multi-page shipping service website that simulates a complete shipment flow — from placing an order to confirming it via email and tracking it under "My Orders".

## 🌐 Overview

QuickShip is a frontend-driven shipping website built using **HTML** and **CSS**, connected to a backend with SQL for data storage and form processing. It demonstrates a typical user journey for online shipment services with authentication and order confirmation features.

---

## ✨ Features

- 🖥️ Multi-page responsive website (Home, Services, Contact, My Orders)
- 🔐 User authentication and form validation
- 📧 Email confirmation on successful order placement
- 📦 “My Orders” dashboard for order updates
- 💾 SQL database for storing user and order information
- 🚀 Frontend deployed on **Render**
- ☁️ Backend + DB hosted on **Clever Cloud**
